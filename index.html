Dúvidas frequentes

Antes de começar, veja o que você precisa saber.

Preciso saber qual é o sistema da minha TV?

Não. No funil existe a opção “Não sei qual é o sistema”. Nesse caso, a pessoa é encaminhada ao WhatsApp com uma mensagem pedindo ajuda para identificar o aparelho.

O teste é liberado automaticamente?

Nesta versão, o site prepara a instalação e envia os dados ao WhatsApp. A liberação final é feita por você no painel do servidor.

O site funciona no GitHub Pages?

Sim. Todo o projeto usa HTML, CSS e JavaScript no navegador, sem precisar de banco de dados ou backend para o funil e o redirecionamento ao WhatsApp.

Posso alterar aplicativos, códigos e instruções?

Sim. No início do JavaScript existe o objeto CONFIG, onde você pode trocar WhatsApp, link do APK, código do Downloader, nomes dos aplicativos e planos.
